Doom Fire

The fire of the PlayStation port of Doom, in three languages at the same time. Change a value, and the three fires change together.

Source on GitHub

The address of the page keeps the values, so you can share a fire with a link.

The same step in each language

Each step sets the bottom row to the source. Then every other pixel takes the pixel below it, moved by the wind, minus a random decay.

Made by rahelmartim. The algorithm is from Fabien Sanglard.
